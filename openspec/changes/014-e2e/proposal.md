# Proposal: E2E Acceptance v2

## Why
Приёмка полного продукта: ядро + встречи/контексты/настройки/скриншоты/TTS/переводы — на реалистичном мок-собеседовании.

## What Changes
- Расширенный приёмочный чек-лист (11 требований)
- Runbook: подготовка, прогон, пост-анализ, тюнинг
- Acceptance gate → релиз-кандидат

## Scope
- 40-минутной прогон с живым интервьюером
- Замеры: латентности, точность, stealth, ресурсы, UI-фичи

## Non-Goals
- Нагрузочное тестирование, A/B моделей

## Affected Specs
- e2e (полная замена)
